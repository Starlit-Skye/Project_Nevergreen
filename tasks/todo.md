## Project Overview

- Player team vs Enemy team.
- Rank-based positioning (1-4).

- Cecilia defeat condition (lose if "ceci" is defeated).

## Repository Architecture
- `Assets/Scripts/Combat/`: Core battle logic (BattleSystem, CombatCharacter, StatusProcessor).
- `Assets/Scripts/Data/`: Static data definitions (CharacterData, SkillData).
- `Assets/Editor/Tests/`: Automated testing suite.
- `Docs/`: Source-grounded documentation.
