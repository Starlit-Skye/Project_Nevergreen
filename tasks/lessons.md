# Lessons Learned

## Communication & Workflow

### 1. Investigation vs. Implementation
- **Pattern**: When the user asks to "investigate and propose solutions," do NOT implement the code change immediately.
- **Rule**: Provide the analysis, explain the root cause, and list the proposed steps. Wait for the user's approval before modifying the codebase.
- **Why**: Jumping to implementation skips the critical review phase and may introduce changes the user isn't ready for or wants to discuss first.
