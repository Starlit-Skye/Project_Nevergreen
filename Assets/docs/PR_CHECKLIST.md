# Game Docs PR Checklist

Use this in pull requests that modify gameplay, systems, architecture, or content pipeline.

- [ ] Updated relevant docs under `docs/`
- [ ] Set `Last verified` date
- [ ] Set `Verified commit` SHA
- [ ] Set `Target build` (engine version + platform)
- [ ] Added/updated `Source of Truth` references
- [ ] Documented timing and determinism assumptions
- [ ] Added authority/prediction notes for multiplayer changes (if applicable)
- [ ] Marked unknowns as `Unknown` with `Missing Evidence`
- [ ] Added or updated acceptance tests (automated and/or playtest cases)
